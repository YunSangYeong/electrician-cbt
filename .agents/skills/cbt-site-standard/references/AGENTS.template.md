# 자격증 CBT 개발 지침

이 프로젝트의 CBT 신규 제작·수정·검증 작업은 먼저
[CBT 사이트 표준](.agents/skills/cbt-site-standard/SKILL.md)과 필요한 references를 읽고 수행한다.
사용자 지시와 상위 지침을 우선하며 기존 프로젝트 규칙과 변경을 보존한다.

- 전기기능사 기준 앱의 최종 화면과 기능을 참고하되 대상 자격증의 시험 규칙·문항은 별도로 검증한다.
- 학습 기준·연도 버전 선택 메뉴는 만들지 않는다. Space 다음 문제는 실전·랜덤 모두 지원한다.
- 대상 자격증명·과목·출제 수·시간·보기·배점·합격·과락, 문제 출처·이용 조건을 확인한다. 전기기능사 수치를 복사하지 않는다.
- 기존 데이터와 Git 이력을 덮어쓰지 않는다. 다른 자격증 자료나 기출 연도·출처를 창작하지 않는다.
- 코드 구현, 필요한 테스트와 빌드, 허용된 저장소 반영, 정확한 커밋의 실제 배포 확인을 구분해 수행·보고한다.
- 스킬 목록에 없더라도 파일을 읽어 적용한다. 파일 복사를 계정 공통 스킬 설치로 표현하지 않는다.

이 문서는 새 저장소의 루트 AGENTS.md에 적용하는 양식이다. 기존 파일이 있으면 통째로 교체하지 말고 위 참조와 필요한 규칙만 병합한다.
