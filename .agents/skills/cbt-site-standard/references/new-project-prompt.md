# 새 클라우드 프로젝트에서 사용할 요청

아래를 복사한 뒤 자격증과 대상 저장소를 채운다. 다른 조건은 필요할 때만 추가한다.

```text
YunSangYeong/electrician-cbt 저장소의
.agents/skills/cbt-site-standard/SKILL.md와 references 폴더를 읽고,
지금 완성된 CBT를 표준으로 아래 자격증 CBT를 만들어줘.

- 대상 자격증: [자격증명]
- 작업할 GitHub 저장소: [사용자명/새저장소]
- 배포: GitHub Pages
- 추가 요구: [있으면 기입]
- 문제은행 목표 수: [지정하거나 공식 분포·검증 가능 범위에 맞게 제안]

먼저 스킬 폴더를 이 저장소에 복사하고,
기존 AGENTS.md를 보존하면서 연결해줘.
표준에 고정한 기준 커밋의 코드를 참고해 UI와 학습 기능을 재사용해줘.
학습 기준 선택 메뉴는 없애고, 두 모드 모두 Space로 다음 문제에 이동하게 해줘.

대상 자격증의 공식 시험 규칙·과목·문항 수·시간·합격·과락을 확인해 적용하고,
기출·복원·자체 제작과 계산 조건 변형을 구분해 보고해줘.
전기기능사 문제를 다른 자격증 문제로 복사하지 말아줘.
코드 구현, 필요한 단위·PC/모바일 테스트와 빌드,
허용된 GitHub 반영 및 해당 커밋의 실제 배포 결과까지 확인해줘.
```

## 프로젝트에 따라 추가할 내용

- 공식 자료 URL, 사용이 허용된 원문·정답·이미지 파일, 확인된 이용 조건.
- PC/모바일 이외의 대상 기기, 추가 언어, 특별한 배점/과락/문항 형식.
- 블로그 iframe 사용 여부, 사용자 정의 도메인, 특별한 저장·백업 요구.

공식 자료나 배포 권한이 없는 경우 AI가 알아서 확보했다고 가정하지 않는다. 원본 저장소와 새 저장소에 대한 접근도 실제로 확인해야 한다.
