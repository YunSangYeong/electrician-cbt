React + TypeScript + Vite, localStorage, 서버·로그인·유료 API 없음이 원본의 구조다. Node.js는 24.19.0, package engines는 22.12.0 이상이다. 원본 소스는 MIT, 자체 문제 데이터는 CC BY 4.0으로 구분되어 있으나 새 자료의 권리를 대신하지 않는다.

## 최신 UX에서 빠뜨리면 안 되는 것

- 학습 기준/연도 버전 드롭다운은 **없다**. 이전 선택 때문에 시작 버튼이 막히지 않도록 복원한다.
- 실전과 랜덤 **모두** 답안 선택 후 Space로 다음 문제에 이동한다. 실전은 정답을 공개하지 않는다.
- 답안 선택 후와 이동 후 문제 본문 포커스, 입력·메뉴·대화상자 보호, 마지막 문제 자동 제출 방지.
- 실전은 별도 제출 확인과 절대 시각 기반 자동 제출, 새로고침 보존을 사용한다.
- 기본 URL이 바뀌지 않는 배포와 블로그 iframe 사용을 고려한다.

## 원본 수치 — 새 자격증 규칙으로 복사하지 말 것

원본은 전기이론·전기기기·전기설비 각 20개로 60문항, 60분, 객관식 4지선다, 60점 합격·과락 없음이라는 학습용 구성을 사용한다. 균등 20문항과 난이도가 공식 시험 분포를 재현한다고 입증된 것은 아니다.

문제은행은 과목별 300개, 총 900개이며 모두 자체 제작이다. 원문 기출 0개·복원 0개다. 기존 90개와 추가 개념형 90개 및 24개 유형 × 조건 30개 = 계산 변형 720개로 구성했다. 계산형 합계는 747개, 비계산 개념형은 153개다. 내부 검토·자동 계산 검증은 외부 전문가 검수 또는 공식 출제기준 대조와 다르며 원본에는 후자가 완료되지 않았다.

원본에서 확인한 단위 테스트 767개·PC/모바일 브라우저 테스트 18개는 기준 시점 결과다. 신규 프로젝트의 실행 결과를 그대로 대체하지 않는다. 원본 기록 보관 한도는 응답 5,000개·시험 30회이고 백업 내보내기는 있으나 UI 복원은 없다.
