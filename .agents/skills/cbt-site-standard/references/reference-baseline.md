React + TypeScript + Vite, localStorage, 서버·로그인·유료 API 없음이 원본의 구조다. Node.js는 24.19.0, package engines는 22.12.0 이상이다. 원본 소스는 MIT, 자체 문제 데이터는 CC BY 4.0으로 구분되어 있으나 새 자료의 권리를 대신하지 않는다.

## 최신 UX에서 빠뜨리면 안 되는 것

- 학습 기준/연도 버전 드롭다운은 **없다**. 이전 선택 때문에 시작 버튼이 막히지 않도록 복원한다.
- 실전과 랜덤 **모두** 답안 선택 후 Space로 다음 문제에 이동한다. 실전은 정답을 공개하지 않는다.
- 답안 선택 후와 이동 후 문제 본문 포커스, 입력·메뉴·대화상자 보호, 마지막 문제 자동 제출 방지.
- 실전은 별도 제출 확인과 절대 시각 기반 자동 제출, 새로고침 보존을 사용한다.
- 기본 URL이 바뀌지 않는 배포와 블로그 iframe 사용을 고려한다.

## 원본 수치 — 새 자격증 규칙으로 복사하지 말 것

원본은 전기이론·전기기기·전기설비 각 20개로 60문항, 60분, 객관식 4지선다, 60점 합격·과락 없음이라는 학습용 구성을 사용한다. 균등 20문항과 난이도가 공식 시험 분포를 재현한다고 입증된 것은 아니다.

문제은행은 과목별 300개, 총 900개이며 모두 자체 제작이다. 원문 기출 0개·복원 0개다. 기존 90개와 추가 개념형 90개 및 24개 유형 × 조건 30개 = 계산 변형 720개로 구성했다. 계산형 합계는 747개, 비계산 개념형은 153개다. 내부 검토·자동 계산 검증은 외부 전문가 검수 또는 공식 출제기준 대조와 다르며 원본에는 후자가 완료되지 않았다.

원본에서 확인한 단위 테스트 767개·PC/모바일 브라우저 테스트 18개는 기준 시점 결과다. 신규 프로젝트의 실행 결과를 그대로 대체하지 않는다. 원본 기록 보관 한도는 응답 5,000개·시험 30회이고 백업 내보내기는 있으나 UI 복원은 없다.

## 표준 v1.1.0의 문제은행 수량

2026-10-20 개정 표준의 새 프로젝트 목표와 완료 기준은 검수 완료 1,000문항이다. 위 고정 앱 커밋의 실제 데이터 900문항은 과거 구현 사실로 유지한다. 이 스킬 개정이 원본 앱의 문항을 1,000개로 늘린 것은 아니다. 새 프로젝트는 대상 자격증의 문항을 별도로 확보·작성·검수한다.

## 표준 v1.2.0의 상단 안내 정책

앱 코드 기준 커밋은 그대로 유지한다. v1.2.0은 그 위에 적용하는 문서·UI 정책 개정이며 새로운 앱 커밋의 배포 검증을 뜻하지 않는다. 기준 소스를 복사하더라도 상단에 비공식·검증 대기·잠정 규칙 안내 배너를 추가하지 않는다. 구판 소스의 `criteria-note` 등 상단 상태 안내도 새 프로젝트에서는 복사 대상에서 제외한다. 색상 변경이나 문구 변경으로 같은 안내를 재생성하지 않는다.

비공식 표시는 푸터/사이드바에 간결하게 두고, 시험 규칙의 확인 상태와 출처·검수 한계는 문제은행 관리/출처 상세·README/검증 문서에 기록한다. 저장 실패·기록 손상 등의 실제 오류 경고 및 시험 이어하기·제출 확인 동작은 유지한다. PC·모바일의 각 화면에서 이를 인수 확인한다.

## 표준 v1.3.0의 사용자 최종 배포 정책

앱 기준 커밋과 과거 배포 기록은 그대로 유지한다. 신규 작업에서는 구현·검증·허용된 Git 반영·배포 준비를 에이전트의 범위로 정하고, 최종 배포는 사용자가 직접 진행한다. 기준 앱의 push 자동 배포 workflow를 그대로 복사하지 말고 검증 CI와 사용자 수동 실행 배포로 분리한다. 배포 없이 준비와 사용자 실행 절차를 인계하면 해당 개발 범위를 완료할 수 있다. 사용자 미배포를 배포 실패나 개발 차단으로 처리하지 않는다. Pages 활성화·설정 변경·배포·재배포는 사용자 실행이며, 공개 검증은 사용자 배포 후 요청에 따라 읽기 전용으로 수행한다.
