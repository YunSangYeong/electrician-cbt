# 프로젝트 요구사항

- 프로젝트명 / 저장소 / 대상 브랜치:
- 사용자와 해결할 문제:
- 핵심 사용 흐름:
- 필수 기능 / 선택 기능:
- PC·모바일·언어·키보드 요구:
- 기존 기술 / 런타임 / lockfile:
- 데이터 저장과 새로고침 복원:
- 데이터 유형·목표 수·독립 유형 수·계산 변형 허용 범위:
- 출처·이용 권한·공식 기준 버전 확인 방법:
- 배포 대상 / 외부 반영이 허용된 범위:
- 준비된 비밀 변수의 이름만 / 필요한 네트워크 목적지:
- 완료 조건과 실제 검증할 시나리오:
- 추정한 기본값 / 진행을 막는 미확정 사항:

값이나 수량을 모르거나 검증하지 않았으면 미확인으로 기록한다. 비밀값을 적지 않는다.
