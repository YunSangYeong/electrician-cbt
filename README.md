# 전기기능사 필기 CBT

React + TypeScript + Vite로 만든 무료 정적 학습 사이트입니다. 서버·유료 API·로그인 없이 PC와 스마트폰에서 실행합니다. **Q-Net 또는 한국산업인력공단의 공식 서비스가 아닙니다.**

## 현재 구현

- **실전 모의시험**: 과목별 20개씩 무작위 60문항, 60분, 4지선다, 60점 합격, 과락 없음. 한 문제씩 표시, 번호 패널·이전/다음 이동, 미응답 표시, 답안 변경, 북마크, 제출 확인창.
- 타이머는 1초씩 차감하는 누적 방식이 아닌 **저장된 종료 시각 − 현재 시각**으로 계산합니다. 새로고침·탭 비활성화 후 복원하며 만료 시 자동 제출하고 중복 채점을 막습니다. 브라우저를 닫은 동안에는 프로세스가 실행되지 않으므로, 만료 후 다시 열 때 자동 제출합니다.
- 시험 중 정답·해설은 표시하지 않습니다. 제출 후 점수·합격/불합격·정답/오답/미응답·과목별 정답률, 전체 보기와 해설, 오답 필터 및 해당 시험 오답만 다시 풀기를 제공합니다. 미응답은 오답에 포함됩니다.
- **랜덤 문제풀이**: 전체/과목 선택, 한 순회 내 중복 방지, 답안 선택 즉시 채점, 정답과 상세 해설·출처·문제 유형, 연속 정답, 학습 중 정답률, 이전 학습 이어하기.
- **학습 관리**: 오답노트, 북마크, 과목별 통계·취약 과목, 최근 시험 점수 그래프·기록, 학습 기록 JSON 백업, 초기화. 오답은 재학습에서 정답을 맞히면 제거됩니다.
- **문제은행**: 버전별 JSON 분리, 검색, 상태 필터, 페이지당 20개, JSON/CSV 일괄 등록·중복 제거·검증 대기·수동 검수 승인·전체 내보내기.
- 모바일 메뉴 및 세로 화면, 응답형 문제 패널, 큰 답안 선택 영역, 키보드 포커스, 접근성 이름, 기본 HTML 확인 대화상자 지원. 외부 폰트나 CDN에 런타임 의존하지 않습니다.

## 실제 문제 확보 수량과 검증 결과

| 과목 | 원문 기출 | 복원 | 자체 제작 | 내부 검수 완료 |
| --- | ---: | ---: | ---: | ---: |
| 전기이론 | 0 | 0 | 30 | 30 |
| 전기기기 | 0 | 0 | 30 | 30 |
| 전기설비 | 0 | 0 | 30 | 30 |
| **합계** | **0** | **0** | **90** | **90** |

**실제 기출을 확보했다고 주장하지 않습니다.** 2026-10-18에 Q-Net 공식 페이지 접근을 시도했지만 클라우드 네트워크 프록시의 HTTP 403 차단으로 원문을 읽지 못했습니다. 2012~2016 공개 기출 및 다른 연도·회차 자료는 이번 버전에 수록하지 않았으며, 민간 문제 사이트에서 무단 복제하지 않았습니다.

90개 문항은 모두 이 프로젝트에서 자체 작성했습니다. 기본 개념·보기·정답·해설을 내부 검토하고, **계산형 27개는 별도 계산식으로 재계산하여 정답과 유일한 정답 보기까지 자동 검증**합니다. 개념형 63개에 대한 외부 전문가의 독립 검수는 아직 받지 않았습니다. `reviewed`는 내부 검수를 뜻하며 공적 인증이 아닙니다. 출제 연도·회차는 모두 `null`이고 자체 제작 출처와 이용 조건을 표시합니다.

- **2024–2026**: 기본 선택 버전. 90개 연습문항으로 학습과 첫 60문항 시험을 실행할 수 있습니다. **공식 출제기준과의 항목별 대조는 대기 중**입니다.
- **2027–2029**: 별도 빈 JSON으로 분리. 공식 기준 확인과 문항 검수 전에는 기본 시험 및 학습 시작을 제공하지 않습니다.
- 실제 출제 비율과 난이도를 그대로 재현한 것은 아닙니다. 과목별 균등 20문항은 학습용 정책입니다. 개정 법령·KEC의 상세 수치 문항은 공식 자료 검증 후 보강해야 합니다.

자세한 데이터 스키마, 출처·저작권 검수 절차와 등록 방법은 [문제은행 안내](docs/QUESTION_BANK.md)를 참고하세요.

## 로컬 실행

Node.js **24.19.0**을 사용해 검증했습니다(`.node-version`). 최소 지원 버전은 22.12.0입니다.

```bash
npm ci
npm run dev
```

기본 경로는 `/electrician-cbt/`입니다. Vite가 표시하는 주소에서 이 경로를 엽니다. 배포용 빌드와 정적 실행:

```bash
npm run build
npm run preview
```

GitHub Pages 프로젝트 경로에 맞춰 `vite.config.ts`의 `base`를 `/electrician-cbt/`로 지정했습니다. 다른 저장소 이름으로 옮기면 이 값도 변경하세요. 화면 전환은 클라이언트 내부 상태를 사용해 Pages에서 별도 서버 라우팅이 필요하지 않습니다.

## 테스트

```bash
npm test                          # Vitest 단위 테스트
npm run build                     # TypeScript 검사 + 프로덕션 빌드
npx playwright install chromium   # 최초 1회 브라우저 설치
npm run test:e2e                  # 빌드 후 프로덕션 정적 서버에서 Playwright
```

이미 시스템 Chromium이 설치된 클라우드에서는 추가 다운로드 없이:

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

검증 범위:

- 단위 **42개**: 90문항 스키마·출처·고유성·균형, 계산 27개, 과목별 20문항 추출, 35/36개 정답 합격 경계, 답안 변경·만료 후 변경 방지·중복 제출 방지·절대시각 복원, 랜덤 비중복·오답 복습·연속 정답, CSV 인용·중복·오류·손상 데이터 처리.
- 브라우저 **14개**: 데스크톱 Chromium과 Pixel 7 크기의 모바일 Chromium에서 각 7개 시나리오. 시험 진행·새로고침·채점·정답 해설·오답 복습, 가상 시계로 60분 경과 자동 제출, 즉시 채점·북마크·통계, JSON/CSV 가져오기·검수·초기화, 만료 재접속, 손상 저장소 보존 및 가로 넘침 검사.
- 모바일 테스트는 에뮬레이션이며 실제 iOS Safari·Android 기기 검증은 별도입니다.

## GitHub Pages 배포

자동 배포 구성: [`.github/workflows/pages.yml`](.github/workflows/pages.yml).

1. GitHub 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다. 저장소 정책에서 Actions 및 Pages 사용이 허용되어야 합니다.
2. `main`에 푸시하거나 **Actions → Test and deploy GitHub Pages → Run workflow**를 실행합니다.
3. 단위 테스트·TypeScript 빌드·PC/모바일 브라우저 테스트 성공 후 정적 산출물(`dist`)을 업로드하고 Pages로 배포합니다. PR은 검증만 수행합니다.
4. `deploy` 작업과 Pages 설정에서 실제 게시 완료를 확인합니다.

예상 공개 주소: **https://YunSangYeong.github.io/electrician-cbt/**

이 주소는 저장소명 기준의 예상 주소입니다. 로컬 빌드 성공이나 workflow 파일 존재는 실제 공개 배포 성공을 뜻하지 않습니다. 클라우드에서 GitHub API·Pages 호스트가 네트워크 정책으로 차단되면 Pages 활성화와 Actions 결과를 확인할 수 없으며 저장소 설정에서 확인해야 합니다. 실제 배포 확인 상태는 작업 완료 보고에서 구분합니다.

## 학습 기록과 확장

- `localStorage` 키: `electrician-cbt:v1`. 브라우저·프로필·사이트 origin마다 별도이며 로그인·서버 동기화가 없습니다. 개발 서버와 Pages의 기록은 공유하지 않습니다.
- 최근 **5,000개 응답**과 **30회 시험**까지 보관합니다. 대시보드·과목별 정답률은 보관 중인 응답 기준입니다. 연습의 연속 정답과 세션 통계는 해당 학습 세션 기준입니다.
- 기록은 답안을 선택할 때 자동 저장합니다. 저장 공간 부족이나 저장소 차단 시 경고를 표시합니다. 손상된 데이터는 자동 덮어쓰지 않고 원본 백업과 초기화를 제공합니다. 브라우저 데이터 삭제나 초기화 시 기록이 사라지므로 백업을 권장합니다. 현재 기록 백업 파일의 UI 복원 기능은 미구현입니다.
- 일괄 등록은 브라우저 내 로컬 등록입니다. 공용 문제은행을 변경하거나 GitHub로 자동 전송하지 않습니다. 내보낸 문항은 별도 리뷰 후 저장소 JSON에 반영합니다.
- 서버 없는 학습 앱이므로 정답은 정적 파일에 포함됩니다. 시험 중 UI만 해설을 숨기며 감독 시험·정답 보안·변조 방지를 제공하지 않습니다. 타이머는 기기 시계 기준입니다.

```text
src/
  App.tsx                한국어 UI와 학습 화면
  model.ts               시험·채점·시간·복습·데이터 검증 로직
  data/
    questions-2024-2026.json
    questions-2027-2029.json
public/templates/         CSV/JSON 등록 양식
scripts/generate_bank.py  최초 자체 제작 문항 원고와 결정적 보기 배치
tests/                   단위 테스트 및 브라우저 시나리오
```

`generate_bank.py`는 유지보수용 원고이며 설치·배포 시 자동 실행하지 않습니다. 수작업으로 확장한 JSON을 재생성으로 덮어쓰지 마세요. 수천 문항으로 확장 시 버전/단원별 데이터 분할과 IndexedDB 전환을 검토해야 합니다. 현재 페이지 목록은 20개씩 렌더링하지만 기본 데이터는 한 번에 읽습니다.
