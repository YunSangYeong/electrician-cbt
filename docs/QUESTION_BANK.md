# 문제은행과 검수 정책

## 실제 확보 현황

- 원문 기출 **0개**, 복원문제 **0개**, 자체 제작 **90개**.
- 과목별 30개. 60문항 모의시험에서는 각 과목 20개를 추출한다.
- 기본 90개 문항은 모두 내부 검토 상태(`reviewed`)이다. 외부 전문가의 검수나 Q-Net의 인증을 의미하지 않는다.
- 계산 메타데이터가 있는 27개 문항은 생성 스크립트와 분리된 식으로 단위 테스트한다. 정답 보기와 동일한 물리량을 나타내는 선택지가 정확히 하나인지도 확인한다.
- 개념형 63개 문항은 설명·보기·정답을 작성 과정에서 검토했다. 아직 외부 독립 검수는 받지 않았다.
- 기본 문항의 실제 출처는 이 프로젝트의 자체 작성 데이터 파일이다. 연도와 회차는 모두 `null`이다. 버전 `2024-2026`은 학습 자료 묶음의 이름이며, 실제 출제 연도가 아니다.

## 조사 한계와 공식 자료

2026-10-18 환경에서 Q-Net 종목정보 페이지 접속을 시도했으나 네트워크 프록시의 403 차단으로 본문과 첨부자료를 읽지 못했다. 따라서 Q-Net 공개자료, 2012~2016년 기출 원문, 다른 연도·회차의 원문은 확보하지 않았다. 이용 권한을 확인할 수 없는 민간 사이트의 문제는 수집하거나 복사하지 않았다.

추후 [Q-Net 공식 사이트](https://www.q-net.or.kr/)의 전기기능사 종목정보 및 고객지원 자료실의 출제기준·공개문제에서 원문, 적용 기간, 공개 범위와 이용 조건을 확인해야 한다. 아래 링크는 조사 출발점이며 검증 완료된 문항 출처가 아니다.

- https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=7780
- https://www.q-net.or.kr/

`2024-2026`에는 전기이론·전기기기·전기설비의 기본 개념과 계산을 수록했지만 공식 출제기준 문서와의 항목별 대조는 **대기 중**이다. `2027-2029`는 별도 빈 파일로 관리한다. 공식 기준 대조와 검수 문항 확보 전에는 그 버전의 기본 시험을 시작할 수 없다. 법령·KEC의 개정 수치를 검증 없이 창작하지 않기 위해 설비 영역은 안전·계측·기본 원리 위주다. 실제 시험의 빈도와 난이도를 재현한다고 보장하지 않는다.

## 데이터 형식

`src/data/questions-2024-2026.json`, `src/data/questions-2027-2029.json`은 문항 객체의 배열이다. UI와 분리하여 버전 관리한다. 런타임 타입과 검증 함수는 `src/model.ts`에 있다.

| 필드 | 내용 |
| --- | --- |
| `id` | 전역 고유 영문·숫자·`_`·`-`, 최대 100자 |
| `subject` | `전기이론`, `전기기기`, `전기설비` |
| `topic`, `question` | 세부 단원과 문제 본문 |
| `choices` | 서로 다른 보기 문자열 4개 |
| `answer` | **1부터 시작**하는 정답 번호 1~4 |
| `explanation` | 공식·대입·계산 또는 개념 설명 |
| `difficulty` | `하`, `중`, `상` |
| `year`, `session` | 확인된 연도(정수)·회차(문자열), 없으면 `null` |
| `type` | `past` 원문 기출 / `reconstructed` 복원 / `original` 자체 제작 |
| `sourceUrl` | 원문 또는 자체 제작 자료의 HTTPS 출처 |
| `verificationStatus` | `reviewed` 내부 검수 완료 / `pending` 검증 대기 |
| `reviewNote` | 검수 근거와 한계 |
| `version` | `2024-2026` / `2027-2029` |
| `rights` | 공개 이용 허용 근거, 라이선스, 권리자 등 |
| `calculation` | 선택 사항. 계산 종류·입력·결과·단위, 기본 계산형 테스트용 |

자체 제작 문항에 실제 출제 연도·회차를 부여할 수 없다. 원문 기출의 `reviewed` 처리에는 최소 확인된 연도와 구체적인 출처 및 이용 권한 확인이 필요하다. 복원 자료 역시 검증되지 않은 연도·회차를 기입하지 않는다.

## 대량 등록

화면의 **문제은행 관리 → JSON / CSV 가져오기**를 이용한다. 파일은 최대 8MB, 한 번에 최대 10,000문항이다. CSV는 `public/templates/questions.csv`, JSON은 `public/templates/questions.json`을 참고한다. CSV에서 `choices` 배열은 `choice1`~`choice4` 열로 나누고 `year`·`session`의 빈칸은 null로 읽는다. 쉼표, 줄바꿈, 따옴표가 있는 셀은 CSV 인용 규칙을 사용한다.

1. ID와 문제 본문·보기의 정규화 결과로 중복을 제외한다. 보기 순서만 바꾼 문항도 제외한다. 숫자의 소수점은 보존한다.
2. 문항 하나라도 형식 오류가 있으면 전체 등록을 중단하고 해당 행을 안내한다.
3. 가져온 문항은 입력 파일의 상태와 관계없이 **검증 대기**로 등록한다. 시험과 연습에는 `reviewed` 문항만 사용한다.
4. 검증 대기 필터에서 문항을 펼쳐 정답·해설·출처를 확인한다. 원문 대조, 사용 권한과 계산 교차 검증을 직접 수행한 후 확인란과 검수 근거를 작성해 승인한다. UI는 이용 권한의 진실 여부를 자동 증명하지 않는다.
5. 브라우저에서의 등록과 승인은 **이 브라우저에만** 저장된다. 공용 사이트에 추가하려면 JSON 내보내기 → 리뷰 → 해당 버전 데이터 파일에 병합 → 테스트 → Git 커밋 과정을 거친다. GitHub에 자동 업로드하지 않는다.

단원이나 문제 소재가 겹치지만 문장이 다른 의미상 중복은 사람이 추가 확인한다. 출처 문서·페이지·문제 번호·권한 증빙과 전문가의 독립 검수를 갖추는 것이 다음 단계다.
